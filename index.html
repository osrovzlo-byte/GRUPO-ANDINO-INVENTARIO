Reactivar Nube Firebase (Reglas de Seguridad)

¿Por qué ocurrió esto?

Google Firebase crea las bases de datos en "Modo de Prueba" por 30 días. Al vencer ese periodo, bloquea las conexiones con PERMISSION_DENIED. Tus datos no se han borrado, solo requieren renovar la regla en la consola de Firebase.

Pasos para reactivar en 1 minuto:

  1. Entra en tu consola de Firebase:
    Abrir Reglas de Firebase Console
  2. Ve a la pestaña Reglas (Rules).
  3. Reemplaza el texto existente por estas reglas permanentes: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  4. Haz clic en el botón azul Publicar (Publish).

Una vez publicado, este sistema se reconectará automáticamente en tiempo real.
